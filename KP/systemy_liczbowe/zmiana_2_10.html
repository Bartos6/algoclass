1. System dwójkowy i dziesiętny

System dwójkowy (BIN) używa cyfr 0 i 1. System dziesiętny (DEC) używa cyfr od 0 do 9. Wartość pozycji zależy od podstawy systemu. Pozycje numerujemy od prawej, zaczynając od 0.

Potęga29282726252423222120
Wartość5122561286432168421

2. BIN → DEC

Każdą cyfrę pomnóż przez odpowiednią potęgę 2. Dodaj otrzymane iloczyny.

10112 = 1 × 2³ + 0 × 2² + 1 × 2¹ + 1 × 2⁰ = 8 + 0 + 2 + 1 = 1110

3. DEC → BIN

Dziel liczbę przez 2, zapisując iloraz całkowity i resztę. Powtarzaj dla ilorazu, aż wyniesie 0. Odczytaj reszty od dołu do góry. Liczba 0 ma zapis 0.

13 : 2 = 6  reszta 1 ↑
 6 : 2 = 3  reszta 0 │
 3 : 2 = 1  reszta 1 │
 1 : 2 = 0  reszta 1 │
1310 = 11012
