# AlgoClass – kompletna strona

Zawiera wszystkie dotychczasowe strony ucznia i nauczyciela oraz nowe karty pracy z analizą kodu dla warunków `if` i pętli `while` w Pythonie i C++. Układ kart wzorowany jest na przekazanym pliku `KP3-cpp.html`: wybór numeru zadania, kod, input, pamięć (historie wartości zmiennych), output, sprawdzanie, wypełnianie odpowiedzi, czyszczenie i nawigacja.

Wgraj zawartość archiwum do katalogu głównego repozytorium GitHub Pages. Zachowaj katalogi `css`, `js`, `materials`. Dane uczniów i postępy w tym prototypie są przechowywane wyłącznie lokalnie w przeglądarce.
