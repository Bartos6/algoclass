# AlgoClass — kompletna aktualna wersja demonstracyjna

Archiwum zawiera wszystkie dotychczasowe strony, w tym panel ucznia, karty pracy PDF i interaktywne, panel nauczyciela, bibliotekę zadań, formularz dodawania zadań, zarządzanie klasami oraz przypisywanie zadań klasom.

Wgraj **całą zawartość** archiwum do katalogu głównego repozytorium GitHub Pages, zachowując strukturę katalogów.

Strony startowe: `index.html`, `student.html`, `teacher.html`.
Pozostałe strony: `register.html`, `reset-password.html`, `task.html`, `theory.html`, `task-form.html`, `class-detail.html`.

**Uwaga:** To prototyp bez backendu. Dane zapisywane w przeglądarce nie synchronizują się między urządzeniami.
