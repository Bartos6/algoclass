Teoria

Wszystkie materiały teoretyczne kursu w jednym miejscu.

Instrukcje warunkowe

Instrukcje warunkowe pozwalają programowi podejmować decyzje.

1. Warunki if / else

if wykonuje instrukcje, gdy warunek jest prawdziwy. else obsługuje przeciwny przypadek.

if (x % 2 == 0) {
    cout << "parzysta";
} else {
    cout << "nieparzysta";
}

2. Kilka warunków: if / else if / else

else if pozwala sprawdzać kolejne możliwości.

if (x > 0) cout << "dodatnia";
else if (x < 0) cout << "ujemna";
else cout << "zero";

3. Spójniki AND / OR

&& oznacza AND, a || oznacza OR.

Pętle

Pętle pozwalają wielokrotnie wykonywać fragment programu.

1. Pętla for

for (int i=0; i<5; i++) {
    cout << i;
}

2. Pętla while

Wykonuje instrukcje, dopóki warunek jest prawdziwy.

Tablice

Tablica przechowuje wiele wartości tego samego typu.

1. Tablice jednowymiarowe

int a[3] = {10,20,30};
cout << a[0];
